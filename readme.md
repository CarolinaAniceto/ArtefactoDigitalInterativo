# Descrição do maestro de luz

Inspirei-me no website gesturesynth.com e criei uma espécie de maestro, onde as mãos desenham um caleidoscópio e tocam música ao mesmo tempo.

O input é a câmara e a deteção de mãos (MediaPipe) que dá a posição e a abertura de cada mão. A altura da mão define a nota, a abertura o número de braços de simetria e a velocidade define o volume. A moldura é o elemento estático e o desenho o elemento móvel.

Foi um trabalho que penso que não se relacionar com o projeto de DPI, mas, através dele, consegui explorar diferentes opções para projetos pessoais. 

Ao longo do trabalho, utilizei a inteligência artificial Claude para dar apoio.  Maioritariamente, pedi que me desse referências do site oficial de p5.js (https://p5js.org/reference/), que se pudessem encaixar na visão que tinha para o projeto final. 

Para além disso, utilizei a IA para resolver erros que surgiam no código enquanto o ia fazendo, assim como para correção de pequenos erros no final do processo.
